# History of Countries

A simple, narrated history-video runner for GitHub Actions: title and short brief in; original Gemini script and TTS, relevant photographs and reusable footage, smooth editing, and a YouTube upload package out.

This version reuses the verified writing, Gemini narration, checkpointing and audio tools from History-of-X. It omits character rigs, procedural animated scenes and animation-director workflows.

Implementation and validation are in progress. No finished video is claimed by this initial commit.
